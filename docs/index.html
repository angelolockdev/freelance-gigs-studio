⚙️ Comment Utiliser en Local ?

1. Lancer le Studio Web

Double-cliquez sur open-freelance-studio.bat pour lancer le serveur local Express sur le port 3840.

2. Injection Chrome (CDP)

Lancez start-chrome-debug.bat, connectez-vous, puis cliquez sur Injecter dans l'interface pour pré-remplir en mode brouillon sans risque de ban.

3. Radar d'Opportunités

Scannez les 8 400+ postes et contrats internationaux via l'API MCP publique aidevboard.com et filtrez par Match Score.
