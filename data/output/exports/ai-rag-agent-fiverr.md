## 5. Frequently Asked Questions (FAQ)

### Q: Can this run locally without sending data to third parties?
A: Yes. We can implement local open-source models using Ollama (Llama 3, Mistral) and local ChromaDB for 100% air-gapped data privacy.

### Q: What is MCP (Model Context Protocol)?
A: MCP is Anthropic's open standard allowing AI agents to securely connect with tools, APIs, and file systems without messy custom glue code.
